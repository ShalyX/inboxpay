# Public deployments

This directory contains public onchain deployment evidence only. Addresses and transaction hashes are intentionally public and should be independently verified on the relevant Arc explorer.

- [`arc-mainnet-policy-vault.json`](./arc-mainnet-policy-vault.json) records the Arc Mainnet policy-vault deployment used as infrastructure proof.

These files do not contain Circle wallet IDs, credentials, entity secrets, Gmail data, or authority to perform a financial write.
